@viamrobotics/prime-editor

@viamrobotics/prime-editor is a CodeMirror 6 code editor for Svelte 5. It highlights with Viam’s code tokens, so it follows the light and dark themes, and it can show a diff against another text.

Caution

The public API is unstable until 1.0. Expect breaking changes in minor releases.
  • CodeEditor, one editor with a bindable value.
  • Six languages: TypeScript, JavaScript, JSON, Python, Go, and SQL.
  • Optional line numbers, line wrapping, a placeholder, and readonly and disabled modes.
  • Search and code folding from the keyboard.
  • A unified or split diff view that opens when original is set.
  • An invalid state through aria-invalid.

Installation

Section titled “Installation”

  1. Install the package and its peer. The svelte peer is ^5.29.0.

    • pnpm
    • npm
    • yarn

  2. Import the stylesheet once, after Tailwind. Tailwind skips node_modules when it scans for classes, so the package’s stylesheet points it at the compiled components.

Usage

Section titled “Usage”

Every editor needs a name. Pass aria-label, or aria-labelledby with the id of a visible label.

Two-way binding

Section titled “Two-way binding”

bind:value holds the document. Typing writes it, and assigning it from outside replaces the document.

Function binding

Section titled “Function binding”

A function binding receives each edit and decides what value becomes. This one refuses an edit past 60 characters by not assigning, and transforms every other edit to uppercase. The editor reads value back after each edit, so a refused edit is undone and a transformed one replaces what was typed.

Languages

Section titled “Languages”

language picks the grammar that highlights and indents the document. Omit it for plain text.

Readonly

Section titled “Readonly”

readonly blocks edits. The document stays focusable, selectable, and copyable.

Disabled and placeholder

Section titled “Disabled and placeholder”

disabled turns the editor off. Unlike readonly, it takes no focus and no selection, it leaves the tab order, and the textbox is marked aria-disabled. placeholder is the text shown while the document is empty.

Unified diff

Section titled “Unified diff”

Set original to open the diff view. value is compared against it, and the deleted and inserted lines share one editor.

Split diff

Section titled “Split diff”

Set diff="split" to put original beside value. The original side is readonly. Switching between unified and split rebuilds the editor, and every other prop change reconfigures it in place.

A long diff is mostly unchanged lines. collapseUnchanged folds each run of them into one row that expands on click, and keeps three lines of context around every change. Changing it rebuilds the editor.

Validation

Section titled “Validation”

The editor does not validate the document. Check value yourself, then set aria-invalid to paint the error border and mark the textbox invalid. Point aria-describedby at the message so a screen reader reads it with the editor’s name. Every aria-* attribute goes to the textbox, so aria-errormessage and aria-required work the same way. Every other attribute, such as id, class, or an event handler, goes to the editor’s outer element.

Keyboard

Section titled “Keyboard”
Input Action
Ctrl + F, or Cmd + F on macOS Open the search panel
Enter / Shift + Enter in the search field Go to the next or previous match
Escape Close the search panel
Ctrl + Shift + [, or Cmd + Alt + [ on macOS Fold the block at the cursor
Ctrl + Shift + ], or Cmd + Alt + ] on macOS Unfold the block at the cursor
Click a fold marker in the gutter Fold or unfold that block

The search panel also replaces, unless the editor is readonly. The fold markers share the gutter with the line numbers, so lineNumbers={false} hides both and folding stays on the keyboard. Tab moves focus out of the editor and never indents.
