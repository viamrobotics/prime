Popover

A popover: a non-modal panel anchored to a trigger. Render Popover.Trigger and Popover.Content inside it. The page stays interactive while it is open.

Built on bits-ui Popover.
  • Composed from parts, so the trigger, the panel, and the close button are yours to arrange.
  • open is bindable, two-way or as a getter and setter. State & binding explains both modes.
  • Non-modal: the page stays interactive while the panel is open.
  • The panel floats in a portal, positioned to the trigger, and flips to the other side when there is no room.
  • Closes on Escape and on a press outside, and returns focus to the trigger.

Anatomy

Section titled “Anatomy”

Every part is a property on Popover. Popover renders no element. Popover.Content portals itself to the body. The panel is a dialog, so give Popover.Content an aria-label or aria-labelledby.

Usage

Section titled “Usage”

Two-way binding

Section titled “Two-way binding”

bind:open on the root.

Fully controlled

Section titled “Fully controlled”

Pass bind:open a getter and a setter. The setter can decline a change.

Closing from inside

Section titled “Closing from inside”

Popover.Close closes the panel. It renders a close icon with aria-label="Close" by default. Pass children to replace the icon, and an aria-label if the text does not name the action.

Placement

Section titled “Placement”

Popover.Content takes side and align to place the panel, and sideOffset and alignOffset to nudge it.

Not modal

Section titled “Not modal”

A popover does not lock page scroll, trap focus, or make the rest of the page inert. Tab moves through the panel and on to the rest of the page. Use a dialog when the user must answer before continuing.

Styling

Section titled “Styling”

Every part that renders an element takes class on that element. Popover.Trigger is a real <button> with no look of its own beyond the focus ring, so add button or icon-button. Popover.Close wears icon-button. Popover renders no element, so it takes no class. bits-ui sets the data attributes below. Popover.Content wears z-popover; see z layers.

PartAttributeValue
Triggerdata-stateopen or closed
Contentdata-stateopen or closed
Contentdata-sidethe resolved side of the trigger
Contentdata-alignthe resolved alignment

Keyboard

Section titled “Keyboard”

API

Section titled “API”
PropTypeDefaultDescription
bind:openbooleanWhether the popover is open. Two-way bindable.
childrenSnippetThe Popover.* parts.

Popover.Close

A button that closes the enclosing Popover. It renders a close icon unless given children.

PropTypeDefaultDescription
idstringElement id. null is not accepted.

Plus everything in HTMLButtonAttributes, spread onto the element.

Popover.Content

The floating panel of a Popover, portaled to the body. The panel is a dialog, so give it aria-label or aria-labelledby. It closes on Escape and on a press outside, and returns focus to the trigger.

PropTypeDefaultDescription
idstringElement id. null is not accepted.
dir'ltr' | 'rtl'Text direction of the panel. auto is not accepted, because positioning needs a concrete direction.
side'top' | 'right' | 'bottom' | 'left''bottom'Which side of the trigger the panel opens on.
align'start' | 'center' | 'end''center'Alignment of the panel along the trigger's edge.
sideOffsetnumber4Gap in pixels between the trigger and the panel.
alignOffsetnumber0Shift in pixels along the alignment axis.

Plus everything in HTMLAttributes<HTMLDivElement>, spread onto the element.

Popover.Trigger

The button that toggles a Popover. Add button or icon-button to style it.

Takes extraClasses, children, ...restProps }: Props as its props.
