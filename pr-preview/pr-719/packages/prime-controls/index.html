@viamrobotics/prime-controls

@viamrobotics/prime-controls is a set of compact realtime controls for tool panels. Each number control steps by keyboard and scrubs by dragging its label sideways, so a value can be tuned live without typing. Containers group the controls into panels, folders, and tabs.

Caution

The public API is unstable until 1.0. Expect breaking changes in minor releases.

  • NumberField, one number with a label that doubles as the scrub handle.
  • TextField, one string with a plain label and no scrub.
  • FileField, a native file input that shows the chosen file names and clears them.
  • Point, a 2D, 3D, or 4D vector as one NumberField per axis.
  • Slider, a range input with a NumberField readout beside it.
  • Select, a compact dropdown for choosing one of a list of items.
  • ToggleButtons, a compact row of mutually exclusive buttons.
  • Panel, Folder, and Tabs, the containers that group controls at tool panel scale.
  • A scrub or a drag writes the bound value on every pointer move, so a function binding sees each intermediate value.

Installation

Section titled “Installation”

  1. Install the package and its peers. The svelte peer is ^5.29.0.

    • pnpm
    • npm
    • yarn

  2. Import the stylesheets once, in this order. Tailwind skips node_modules when it scans for classes, so each package’s stylesheet points it at that package’s compiled components.

NumberField

Section titled “NumberField”

NumberField wraps a native <input type="number"> with an optional visible label. The input sits in a prime-ui Input.Group that wears the frame, with prime-ui’s NumberInput.Stepper at its right edge, whose up and down buttons step by step on a pointer press and repeat while held. They show while the field is hovered or focused, take no focus, and are hidden from assistive technology. Without a label, pass aria-label or aria-labelledby, and the field does not scrub. labelPlacement is 'outside' by default, and 'inset' draws the label inside the input’s left edge as a prefix, which fits a short label such as one axis letter.

Two-way binding

Section titled “Two-way binding”

bind:value holds the number. An undefined value renders an empty field, and clearing the field writes nothing: it stays empty while it has focus, takes the next number typed, and shows the bound value again on blur. Drag the label sideways to scrub, or focus the input and press the arrow keys.

Function binding

Section titled “Function binding”

A scrub writes on every pointer move, so a function binding receives each intermediate value. Use one to throttle, to veto by not assigning, or to count writes as this recipe does.

Range and step

Section titled “Range and step”

min and max clamp scrubs and key presses, while typing stays unclamped. step is the amount one key press or one pixel of scrub moves the value, and a fractional step keeps its decimal places, so 0.05 steps never show float residue.

Keyboard and pointer

Section titled “Keyboard and pointer”
Input Action
Arrow Up / Arrow Down Raise or lower the value by step
Shift + Arrow Up / Arrow Down Step by 10 times step
Alt + Arrow Up / Arrow Down Step by a tenth of step
Drag the label sideways Scrub, moving the value by step for each pixel
Shift or Alt while scrubbing Scale each pixel by 10 or by a tenth
Click the label Focus the input
Press the up or down button Step once by step, and repeat while held
Slider: Arrow Left / Right / Up / Down The range moves by step, natively
Slider: Home / End The range jumps to min or max, natively
Slider: readout Steps like a NumberField, without scrubbing

A drag begins once the pointer moves 4 pixels from where it was pressed, and only the primary button scrubs. A disabled or readonly field neither steps nor scrubs. An empty field starts from min, or 0 without one.

Point

Section titled “Point”

Point binds a PointValue, an object with x and y and optionally z and w. x and y always render, and z and w render when defined or listed in axes. Each axis letter sits inside its field as a prefix and is the scrub handle. Editing one axis writes a new object with that axis changed and the others as they were. min, max, step, and disabled apply to every axis.

Function binding

Section titled “Function binding”

The setter receives the whole new PointValue. This one refuses any value farther than 10 from the origin by not assigning, so the point stops at that circle while the drag continues.

Custom labels

Section titled “Custom labels”

labels renames any axis letter, and an axis left out keeps its uppercase name.

In a narrow box

Section titled “In a narrow box”

Point keeps its axes in one row while each has room for its value, and stacks them one a row in a narrower box: under 15rem for two axes, 22rem for three, and 29rem for four. It measures its own box with a container query, so its root is a size container. Give it a width where its parent would otherwise shrink it to its content.

Per axis

Section titled “Per axis”

axes lets single axes set min, max, step, suffix, state, describedBy, and placeholder for themselves, and an axis listed there uses its own value in place of the control’s. So a vector whose last axis has its own unit and range is still one Point. This orientation is four axes, and the last is an angle with its own step, range, and unit.

Details under an axis

Section titled “Details under an axis”

The details snippet draws content under one axis field, at that field’s width, and receives the axis. Here each axis has a button that restores its live value. Y has been edited, so that one field warns through axes, and describedBy points it at the message under it. Pair a warn or error on one axis with such a message, because a color is never the only signal.

Mixed values

Section titled “Mixed values”

An axis whose value is undefined renders empty with its placeholder and stays undefined in every write. An undefined z or w renders only when it is listed in axes. That fits an editor for several objects at once: an axis that differs across them shows a dash, and a write carries numbers only for the axes that have one, so applying those numbers leaves each object’s own value on the others. Here Z differs, and editing X or Y keeps both Z values.

Hints

Section titled “Hints”

NumberField, Point, Slider, ToggleButtons, and a Select with no children take a hint. It puts an info button beside the label that opens a tooltip with the text, and the control is described by the same text, tooltip open or not. The button is named About <label>. A hint needs a visible label, so it sits beside one. Select shows no label, so its button is named from aria-label. Point has one hint for the whole group, and its axis fields have none. An inset NumberField puts the button after the input, since the label is inside it. TextField and FileField take a hint the same way.

Suffix

Section titled “Suffix”

NumberField takes a suffix, a short text such as a unit, drawn inside the input’s right edge in subtle-2. The input sits in a prime-ui Input.Group, which wears the border and the focus ring, and the input inside it goes borderless. An inset label keeps its left padding on the group. The suffix is part of the input’s accessible description, next to a hint and any aria-describedby you pass, so a unit is not only for sighted users. Point draws the suffix in every axis field, and Slider draws it in its readout.

Trailing content

Section titled “Trailing content”

NumberField takes a trailing snippet, drawn inside the input’s right edge after any suffix, in the same Input.Group. It fits an icon button that acts on the one field. Point takes the same snippet and passes it the axis, and Slider draws it in its readout. Content that keeps its box while hidden, as invisible does, keeps the input’s width fixed, so the field does not move when the button appears. Here each axis gets a reset button once its value differs from the live one.

State

Section titled “State”

NumberField, Point, and Slider take a state of 'none', 'info', 'warn', or 'error', prime-ui’s FieldState. 'warn' draws the warning-dark border. 'error' draws the danger-dark border and sets aria-invalid="true". 'info' changes no border, because prime-ui’s input style has no info rule, and this package draws none of its own. Point takes one state for the whole control and gives it to every axis field, and axes sets one on single axes. Slider draws its state on the readout, and an error marks the range invalid and turns its track danger-dark. With a suffix, the border belongs to the group. A color is never the only signal, so pair a warn or error with text, such as a hint.

Every control takes disabled. NumberField and TextField also take readonly, which keeps the value visible and focusable but stops edits, steps, and scrubs. The panels below render each control in each state it supports.

TextField

Section titled “TextField”

TextField is a native text input with the NumberField row layout and no scrub. The label is a plain <label> that focuses the input. Without a label, pass aria-label or aria-labelledby. It takes placeholder, the native input attributes, hint, and state, which work as they do on NumberField. It has no suffix and no labelPlacement.

bind:value holds a string. It starts undefined when the bound state does, and a cleared field binds the empty string, so a bound $state('') stays a string.

FileField

Section titled “FileField”

FileField is prime-ui’s FileInput in the TextField row layout. A native <input type="file"> covers the control, so the picker, a dropped file, and the keyboard are the browser’s, and accept, multiple, and the other native attributes pass through. The label is a plain <label>. Without a label, pass aria-label or aria-labelledby. hint and state work as they do on NumberField.

bind:value holds a File[]. Without multiple it holds at most one file, and a cleared field is an empty array. The chosen names truncate to the row, so the control never grows past a narrow pane, and a clear button appears beside them, named by clearLabel, which defaults to Clear selection. accept only filters the picker, so check the files yourself and set state="error" on one you refuse.

Panel

Section titled “Panel”

Panel is the dense container for a tool panel’s controls, a role="group" with a rounded-sm border and tight spacing. A visible title names the group. Without one, pass aria-label or aria-labelledby.

Folder

Section titled “Folder”

Folder is a collapsible group inside a panel. Its title is the text of the button that opens and closes it. bind:open reads and sets the state. It renders open while the bound value is undefined, so a folder with no initial value starts open.

Indicator

Section titled “Indicator”

indicator is a snippet that replaces the chevron at the end of the title row, after any summary. It receives { open }.

Root attributes

Section titled “Root attributes”

Point, Slider, ToggleButtons, Panel, and Folder spread their remaining props onto the root element, so an id, a data-*, or an aria-* attribute reaches it. On Slider the naming props still name the range and the readout.

Tabs

Section titled “Tabs”

Tabs is a compound of Tabs.List, Tabs.Trigger, and Tabs.Content. It wraps the prime-ui parts at panel scale, so the props and the keyboard behavior are prime-ui’s. bind:value holds the selected tab, and each Tabs.Content shows while its value is selected. Give Tabs.List a visible label, an aria-label, or an aria-labelledby.

Select

Section titled “Select”

Select is prime-ui’s Select at panel scale, with the same parts and keyboard. bind:value holds the selected item’s value. A Select with no children renders the trigger, the value, and the list from items. It takes placeholder and needs an aria-label or aria-labelledby. Its trigger fills its container’s width, and class lands on the trigger, so flex-1 or min-w-0 fits it into a row.

Parts

Section titled “Parts”

Write the parts when you need a class, handlers, or a custom item. Select.Items renders one compact item per entry of items.

ToggleButtons

Section titled “ToggleButtons”

ToggleButtons is prime-ui’s ToggleButtons at panel scale, with the same keyboard. bind:value holds the selected option’s value, and one option is always selected. Give it items, or write ToggleButtons.Item parts when an option needs an icon or a class. The visible label names the group. Without it, pass aria-label or aria-labelledby.

Slider

Section titled “Slider”

Slider pairs a native <input type="range"> with a NumberField readout. The visible label names both. Without it, pass aria-label or aria-labelledby. min, max, and step apply to both, and the readout steps like a NumberField without scrubbing. A disabled range paints a disabled-light track and a disabled-dark thumb, and the readout is disabled with it. trailing draws inside the right edge of the readout. The readout is 64 px wide and grows to fit the longest value in the range, min or max at the step’s decimal places, so a value such as -179.9 is never clipped.

Function binding

Section titled “Function binding”

A drag writes on every pointer move, so a function binding receives each intermediate value, as it does for NumberField. This one counts the writes.
