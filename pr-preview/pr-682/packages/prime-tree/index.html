@viamrobotics/prime-tree

@viamrobotics/prime-tree renders a tree of your own nodes and is headless. The package owns behavior and accessibility, including keyboard navigation, roving focus, selection, and expansion. You own the markup of every row through the node snippet, so the tree draws no chrome.

Caution

The public API is unstable until 1.0. Expect breaking changes in minor releases.

  • Keyboard navigation, type-ahead, and roving focus from the WAI-ARIA tree pattern, built on Zag.
  • Single or multiple selection and expansion, each a bindable array of node values.
  • A node snippet that renders every row, so indentation, icons, and hover styles are yours.
  • Row arrangement hooks for virtual lists and empty-branch placeholders.

Installation

Section titled “Installation”

  1. Install the package and its peers. The svelte peer is ^5.29.0. @viamrobotics/tailwind-config comes with the package as a dependency, and installing it directly as well gives your own classes the same tokens.

    • pnpm
    • npm
    • yarn

  2. Import the package stylesheet once, after Tailwind. Tailwind skips node_modules when it scans for classes, so this file points it at the package’s compiled components and pulls in the @viamrobotics/tailwind-config tokens.

Usage

Basic rows

Section titled “Basic rows”

nodes holds the root nodes and is the single source of truth. A later change to it flows into the tree without a remount. The accessors tell the tree how to read your node type: nodeToValue returns a unique id, nodeToString returns the label used for type-ahead, and nodeToChildren returns the children. nodeToChildrenCount and isNodeDisabled are optional. Return a number from nodeToChildrenCount for a branch that may be empty, such as an empty folder, so it still renders as a branch, and undefined for a leaf. Any number, including 0, makes the node a branch.

The node snippet receives the node and its TreeNodeState. It runs once per visible node. Return a Tree.Branch for a branch or a Tree.Item for a leaf. Inside a branch, Tree.BranchControl holds the row you see, and Tree.BranchContent renders the children.

A collapsed branch never calls the snippet for its children, and indentation is yours: see Styling for --depth.

The second argument of the node snippet is a TreeNodeState.

The second argument of the node snippet is a TreeNodeState.

FieldTypeMeaning

Indentation is yours. Use depth as in the recipe above, or read the --depth custom property that each row carries.

Two-way binding

Section titled “Two-way binding”

bind:expanded and bind:selected hold arrays of node values. selectionMode is 'single' by default and 'multiple' allows several selected rows. expandOnClick defaults to true, so a click on a branch row toggles it.

Fully controlled

Section titled “Fully controlled”

Both props also take a function binding. The setter runs on each change and can refuse it by not assigning. This tree keeps the locked folder from closing.

Custom rows

Section titled “Custom rows”

To arrange the rows yourself, pass a children snippet to Tree or to Tree.BranchContent. It receives the nodes at that level, and you render one Tree.Row per node you want shown, with the node’s index among those nodes. That is how a branch with hundreds of children goes through a virtual list, or how an empty branch shows a placeholder. Tree.IndentGuide is a hook for a vertical guide line.

The nodes a children snippet receives are typed unknown, since a part cannot see the root’s node type. Narrow them once with a helper or a cast.

Branch click

Section titled “Branch click”

branchClick decides what a click, Enter, or Space on a branch row does: 'toggle-and-select' (the default) opens or closes the branch and selects it, 'select' only selects it and leaves opening to the trigger, and 'toggle' only opens or closes it, for a tree whose branches are folders rather than choices. The trigger always toggles.

Styling

Section titled “Styling”

The root renders one element, role="tree", with tabindex="-1". class and every other attribute land on it, so size it with a class and make it the scroll container with overflow-auto when the tree is taller than its box. To reach the element itself, pass an attachment through the rest props.

Each part spreads the attributes you pass over its own, so class, style, and event handlers all work on every part. Each renders children, except that Tree.BranchContent treats children as the row renderer and Tree.Row renders no element of its own. Tree.Item leaves aria-current to you. The package renders only what the snippet returns, so it adds no wrappers or default styles.

The package sets a --depth custom property on Tree.Branch and Tree.Item, and a branch’s control inherits it. Use it in a style attribute for indentation, as the recipes do. state.depth is the script-side equivalent. For the utility classes the recipes wear, such as focus-ring, see the component classes.

Zag sets these data attributes, so Tailwind variants like data-[selected]:bg-medium work without a wrapper.

AttributePartsValue
data-partevery partThe part name, such as branch-control
data-valueBranch, BranchControl, BranchTrigger, ItemThe node’s value
data-depthBranch, BranchControl, Item, IndentGuideNesting depth, starting at 1
data-stateBranch, BranchControl, BranchTrigger, Indicatoropen or closed
data-selectedBranch, BranchControl, Item, Indicatorpresent when selected
data-focusBranchControl, Item, Indicatorpresent on the row holding the roving focus
data-disabledBranch, BranchControl, BranchTrigger, Item, Indicatorpresent when disabled

Focus is roving. One row has tabindex="0" and the rest are reachable by the arrow keys, so the tree is a single tab stop. Rows carry aria-expanded, aria-selected, aria-level, aria-setsize, and aria-posinset. A branch row shows expansion with a visual icon, and Tree.Indicator is aria-hidden, so the label inside the row must name the node. Name the tree itself with aria-label or aria-labelledby.
