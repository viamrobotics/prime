Icon

Renders a curated icon by name (see icons.ts), or with a passed Svelte component.

<Icon
  icon="cog"
  size="xl"
/>
  • A curated name renders inline SVG from the Viam set.
  • Any Svelte icon component renders as-is, so a Lucide icon tree-shakes to only what you import.
  • Eight sizes on the design-system scale. Color follows currentColor.
  • Decorative by default: aria-hidden and not focusable. Add an aria-label when it stands alone.
