`@viamrobotics/prime-panes` renders a binary tree of panes that the user can resize and rearrange. The package is being set up, and its components and usage docs land in the pull requests that follow.

<Aside type="caution">
  The public API is unstable until 1.0. Expect breaking changes in minor
  releases.
</Aside>
