`@viamrobotics/prime-ui` is Viam's Svelte 5 component library. Components are built on top of design tokens from [`@viamrobotics/tailwind-config`](../tailwind-config/) and styled with Tailwind CSS v4.

<Aside type="caution" title="Pre-1.0">
  The v2 of prime is under active development. The public API is unstable.
  Expect breaking changes until 1.0.
</Aside>

## Installation

<Steps>

1. Install the package and its peers:

   <Tabs syncKey="pkg">
     <TabItem label="pnpm">
       <Code
         code="pnpm add @viamrobotics/prime-ui @viamrobotics/tailwind-config svelte tailwindcss"
         lang="sh"
       />
     </TabItem>
     <TabItem label="npm">
       <Code
         code="npm install @viamrobotics/prime-ui @viamrobotics/tailwind-config svelte tailwindcss"
         lang="sh"
       />
     </TabItem>
     <TabItem label="yarn">
       <Code
         code="yarn add @viamrobotics/prime-ui @viamrobotics/tailwind-config svelte tailwindcss"
         lang="sh"
       />
     </TabItem>
   </Tabs>

2. In your app's main CSS, import Tailwind and the prime-ui stylesheet:

   <Code
     code={`@import "tailwindcss";\n@import "@viamrobotics/prime-ui/styles.css";`}
     lang="css"
   />

   Tailwind v4 skips `node_modules` when it detects which classes to generate, so the package ships a stylesheet that points Tailwind at its compiled components. It also imports the tokens from `@viamrobotics/tailwind-config`. If you prefer to manage this yourself, import `@viamrobotics/tailwind-config` and add your own `@source` pointing at `node_modules/@viamrobotics/prime-ui/dist`.

</Steps>

## Usage

```svelte
<script lang="ts">
  import { Field, Input, Label } from '@viamrobotics/prime-ui';

  let value = $state('');
</script>

<Field>
  <Label>Email</Label>
  <Input bind:value />
</Field>
```

## Icons

`Icon` takes an SVG path string or a Svelte icon component. Install `@mdi/js` for the Material Design icons, and import the Viam glyphs from `@viamrobotics/prime-ui/icons`.
