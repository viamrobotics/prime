- Three states, unchecked, checked, and indeterminate, driven by two bindable props: `checked` and `indeterminate`.
- Keyboard and screen reader behavior from the WAI-ARIA checkbox pattern, via bits-ui.
- Submits with the form through a hidden `<input>` when given a `name`.
- The icon is a snippet, so size and color are yours to change.

## Usage

### Two-way binding

`bind:checked` keeps your state and the box in sync. [State & binding](../state/) covers both modes.

<Example code={twoWaySource} title="TwoWay.svelte">

</Example>

### Fully controlled

Give `bind:checked` a getter and a setter. Here the box can be turned on but never off. [State & binding](../state/) has the rule.

<Example code={controlledSource} title="Controlled.svelte">
  <Controlled client:visible />
</Example>

### Custom icon

Pass children to replace the icon. The snippet receives the current `checked` and `indeterminate`, so it can pick a glyph, a size, and a color per state.

<Example code={customIconSource} title="CustomIcon.svelte">
  <CustomIcon client:visible />
</Example>

### In a field

Inside a [`Field`](../field/) the checkbox takes `controlId`, `disabled`, `required`, `state`, and `aria-describedby` from the field, and the label and hint wire themselves to it. `name` and `value` make it part of the enclosing form. A `state` of `error` sets `aria-invalid="true"` and turns the default icon red. Pass `state` directly to override the field's.

</Example>

## Styling

`class` lands on the root button, which is the whole component. bits-ui sets these data attributes on it, so Tailwind variants like `data-[state=checked]:bg-light` work without a wrapper.

| Attribute       | Value                                      |
| --------------- | ------------------------------------------ |
| `data-state`    | `checked`, `unchecked`, or `indeterminate` |
| `data-disabled` | present when disabled                      |
| `aria-invalid`  | `true` when `state` is `error`             |

## Keyboard

| Key              | Action                                                       |
| ---------------- | ------------------------------------------------------------ |
| <kbd>Space</kbd> | Toggles the checkbox.                                        |
| <kbd>Enter</kbd> | Swallowed, so pressing it on the box never submits the form. |
