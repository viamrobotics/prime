- A real `<label>`, so clicking it focuses the control it points at.
- Inside a [`Field`](../field/) it finds the control, mirrors `required` and `disabled`, and names a `RadioGroup` through `aria-labelledby`.
- The required asterisk is a snippet, so it can be any mark you like.

## Usage

### On its own

Outside a field, point it at the control with `for`.

<Example code={standaloneSource} title="Standalone.svelte">
  <Standalone client:visible />
</Example>

### Custom required indicator

Pass an `indicator` snippet to replace the asterisk. It renders only while the label is required.

<Example code={customIndicatorSource} title="CustomIndicator.svelte">
  <CustomIndicator client:visible />
</Example>

## Styling

`class` lands on the `<label>`, an inline flex row with a small gap between the text and the indicator. The asterisk is `aria-hidden`, so it never reaches the accessible name. Set the real requirement on the control.
