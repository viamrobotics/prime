- Composed from parts, so the trigger, the panel, and each item are yours to arrange.
- One `value`, bindable. `items` gives the closed trigger its label.
- Keyboard navigation, typeahead, and the WAI-ARIA listbox pattern, via bits-ui.
- The panel floats in a portal, positioned to the trigger, and scrolls when the list is long.

## Anatomy

Every part is a property on `Select`. `Portal` and `Content` are required for the panel to float. `Viewport` is the scrolling region and is required for the scroll buttons. `Group` and `GroupHeading` are optional.

```svelte
<Select>
  <Select.Trigger>
    <Select.Value />
  </Select.Trigger>
  <Select.Portal>
    <Select.Content>
      <Select.ScrollUpButton />
      <Select.Viewport>
        <Select.Item />
        <Select.Group>
          <Select.GroupHeading />
          <Select.Item />
        </Select.Group>
      </Select.Viewport>
      <Select.ScrollDownButton />
    </Select.Content>
  </Select.Portal>
</Select>
```

## Usage

### Two-way binding

`bind:value` on the root. Pass the same list as `items` so the trigger can show the selected label while the panel is closed.

<Example code={twoWaySource} title="TwoWay.svelte">
  <TwoWay client:visible />
</Example>

### Fully controlled

A function binding makes your setter the only writer, so it can decline a selection. Both modes are explained in [State & binding](../state/).

<Example code={controlledSource} title="Controlled.svelte">
  <Controlled client:visible />
</Example>

### Groups and scroll buttons

Wrap related items in `Select.Group` with a `Select.GroupHeading`. For a list taller than the panel, put `Select.ScrollUpButton` and `Select.ScrollDownButton` around the viewport. They appear only when there is more to scroll in that direction.

<Example code={groupedSource} title="Grouped.svelte">
  <Grouped client:visible />
</Example>

### Custom item content and trigger indicator

An item renders its `label` and a check when selected. Pass children to replace that. The snippet receives `selected` and `highlighted`. The trigger's chevron is an `indicator` snippet in the same way.

## Styling

Each part takes `class` on its own element. `Select` itself renders no element, so it takes none. The panel width follows the trigger through `--bits-select-anchor-width`, and its max height through `--bits-select-content-available-height`, both set by bits-ui. bits-ui sets these data attributes for Tailwind variants.

| Part      | Attribute          | Value                              |
| --------- | ------------------ | ---------------------------------- |
| `Trigger` | `data-state`       | `open` or `closed`                 |
| `Trigger` | `data-disabled`    | present when disabled              |
| `Trigger` | `data-placeholder` | present while nothing is selected  |
| `Value`   | `data-placeholder` | present while nothing is selected  |
| `Content` | `data-state`       | `open` or `closed`                 |
| `Item`    | `data-selected`    | present when selected              |
| `Item`    | `data-highlighted` | present under the pointer or keys  |
| `Item`    | `data-disabled`    | present when disabled              |
| `Item`    | `data-value`       | the item's `value`                 |

## Keyboard

With focus on the trigger:

| Key                                                                  | Action                                  |
| -------------------------------------------------------------------- | --------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | Opens the panel.                        |
| Printable characters                                                 | Opens and highlights the first match.   |

With the panel open:

| Key                                             | Action                                                 |
| ----------------------------------------------- | ------------------------------------------------------ |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>       | Highlights the next or previous item.                  |
| <kbd>Home</kbd> / <kbd>End</kbd>                | Highlights the first or last item.                     |
| <kbd>PageDown</kbd> / <kbd>PageUp</kbd>         | Highlights the item a page away.                       |
| <kbd>Enter</kbd> / <kbd>Space</kbd>             | Selects the highlighted item and closes.               |
| <kbd>Alt</kbd> + <kbd>ArrowUp</kbd>             | Selects the highlighted item and closes.               |
| Printable characters                            | Typeahead: highlights the next item matching the text. |
| <kbd>Escape</kbd>                               | Closes without changing the value.                     |
| <kbd>Tab</kbd>                                  | Closes and moves focus on.                             |
