- Composed from a trigger and a content part, so the layout inside each is yours.
- `open` is bindable, two-way or as a getter and setter. [State & binding](../state/) explains both modes.
- `Collapsible.Content` is only in the document while open.
- The trigger carries `data-state="open"` or `closed` and `aria-expanded`.
- The trigger's children are the title and an optional subtitle. The default chevron turns when open, and `indicator` replaces it.

## Anatomy

Every part is a property on `Collapsible`. The root renders a `<div>`, the trigger a `<button>`.

```svelte
<Collapsible>
  <Collapsible.Trigger>title</Collapsible.Trigger>
  <Collapsible.Content>...</Collapsible.Content>
</Collapsible>
```

## Styling

Every part takes `class` on its element. `Collapsible.Trigger` is a full-width `<button>` with the focus ring and no other look, so add the type and spacing you want. bits-ui sets the data attributes below.

| Part      | Attribute       | Value                 |
| --------- | --------------- | --------------------- |
| `Root`    | `data-state`    | `open` or `closed`    |
| `Root`    | `data-disabled` | present when disabled |
| `Trigger` | `data-state`    | `open` or `closed`    |
| `Trigger` | `aria-expanded` | `true` or `false`     |
| `Trigger` | `data-disabled` | present when disabled |
| `Content` | `data-state`    | `open`                |

## Keyboard

| Key                                 | Action                                  |
| ----------------------------------- | --------------------------------------- |
| <kbd>Tab</kbd>                      | Focuses the trigger.                    |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On the trigger, opens or closes the content. |
