- One `value` for the whole group, bindable, with each `RadioGroup.Item` naming the value it selects.
- Roving focus and arrow-key navigation from the WAI-ARIA radio group pattern, via bits-ui.
- Vertical by default, horizontal with `orientation`.
- Submits with the form through a hidden `<input>` when given a `name`.

## Anatomy

```svelte
<RadioGroup>
  <RadioGroup.Item value="…">label</RadioGroup.Item>
  <RadioGroup.Item value="…">label</RadioGroup.Item>
</RadioGroup>
```

## Styling

`class` on `RadioGroup` lands on the group `<div>`, which is `flex` with `flex-col` or `flex-row` by orientation, so add the gap you want. `class` on `RadioGroup.Item` lands on the item button. bits-ui sets these data attributes for Tailwind variants.

| Element | Attribute          | Value                        |
| ------- | ------------------ | ---------------------------- |
| group   | `data-orientation` | `vertical` or `horizontal`   |
| group   | `data-disabled`    | present when disabled        |
| item    | `data-state`       | `checked` or `unchecked`     |
| item    | `data-value`       | the item's `value`           |
| item    | `data-disabled`    | present when disabled        |
| item    | `data-orientation` | `vertical` or `horizontal`   |

## Keyboard

Focus moves between items, and moving focus with the arrow keys also selects the newly focused item.

| Key                                                            | Action                                              |
| -------------------------------------------------------------- | --------------------------------------------------- |
| <kbd>Tab</kbd>                                                 | Focuses the checked item, or the first if none is.  |
| <kbd>ArrowDown</kbd> / <kbd>ArrowRight</kbd>                   | Moves to and selects the next item, wrapping around. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowLeft</kbd>                      | Moves to and selects the previous item, wrapping.   |
| <kbd>Home</kbd> / <kbd>End</kbd>                               | Moves to and selects the first or last item.        |
| <kbd>Space</kbd>                                               | Selects the focused item.                           |
