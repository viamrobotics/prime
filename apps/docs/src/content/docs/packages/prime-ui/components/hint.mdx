- A `<p>` of helper text that a screen reader announces with the control.
- Inside a [`Field`](../field/) it joins the control's `aria-describedby` on its own. Several hints stack.
- Follows the field's `disabled` and `state`, coloring the text for `error`, `warn`, and `info`. `disabled` wins over all three.

## Usage

### On its own

Outside a field, give it an `id` and name it in the control's `aria-describedby`.

## Styling

`class` lands on the `<p>`, alongside the size and the state color. Two Tailwind text colors on one element resolve by stylesheet order, not class order, so to change the color reliably pass `state` rather than fighting it.
