- [`Input`](../input/) with `type="number"`, so it shares the frame, the states, and the `StateIcon`.
- `value` is a `number`, or `undefined` while the field is empty. No string parsing on your side.
- `min`, `max`, and `step` are the native attributes. The browser owns stepping, spin buttons, and the wheel.

## Styling

Same as [`Input`](../input/#styling): `class` lands on the frame, and `NumberInput.StateIcon` takes `class` on its `<svg>`.

## Keyboard

Native number input behavior: <kbd>ArrowUp</kbd> and <kbd>ArrowDown</kbd> step by `step` within `min` and `max`. Nothing is added or intercepted.
