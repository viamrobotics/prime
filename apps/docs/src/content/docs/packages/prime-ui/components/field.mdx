- Generates the control's id (`controlId`) and hands it to the label's `for` and the control.
- Collects every `Hint` into the control's `aria-describedby`, and names a `RadioGroup` from the label.
- `disabled`, `required`, and `state` set once here reach every part.
- A prop passed to a part directly always wins over the field's value.

## Anatomy

A field is a plain `<div>` around one control, with any number of labels and hints in any order. Its one part is `Field.StateIcon`, which shows the field's `state` as an icon.

```svelte
<Field>
  <Label />
  <Input /> <!-- or NumberInput, Checkbox, RadioGroup, Select -->
  <Hint />
</Field>

<Field>
  <Label />
  <Input.Group>
    <Input />
    <Field.StateIcon />
  </Input.Group>
  <Hint />
</Field>
```

## What the parts take from the field

| Part                        | Reads from `Field`                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------- |
| `Label`                     | `for` (the control id), `required`, `disabled`                                                    |
| `Hint`                      | `disabled`, `state` (error turns red, `warn` and `info` are colored too), and joins the control's `aria-describedby` |
| `Input`, `NumberInput`      | `controlId`, `disabled`, `required`, `state`, `aria-describedby`                                  |
| `Checkbox`                  | `controlId`, `disabled`, `required`, `state`, `aria-describedby`                                  |
| `RadioGroup`                | `controlId`, `disabled`, `required`, `state`, `aria-labelledby`, `aria-describedby`               |
| `Select` / `Select.Trigger` | `disabled` and `required` on the root, and `controlId`, `state`, and `aria-describedby` on the trigger       |
| `Field.StateIcon`           | `state`, and renders nothing for `none`                                                           |

A `Hint` in an `error` field is described by the control, not announced. To have a screen reader read an error the moment it appears, pass `role="alert"` to that `Hint`. It goes straight to the `<p>`.

## Without a field

Every part still works on its own. Wire it by hand with `for`, `id`, and `aria-describedby`:

```svelte
<Label for="email" required>Email</Label>
<Input id="email" aria-describedby="email-hint" required />
<Hint id="email-hint">We'll never share it.</Hint>
```

## Styling

`Field` renders a bare `<div>` and takes no layout stance, so pass `class` to stack or inline its parts. `controlId` is the id the field assigns to the control. Pass your own to point an external `<label for>` or a test selector at it. A plain `id` lands on the wrapper `<div>`.
