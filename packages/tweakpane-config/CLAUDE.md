# @viamrobotics/tweakpane-config

Viam-themed configuration for [`svelte-tweakpane-ui`](https://kitschpatrol.com/svelte-tweakpane-ui). Exposes a preset `Theme` matching the Viam design system, which consumers apply through `svelte-tweakpane-ui`'s own `ThemeUtils` API.

## Surface

- `primeTheme` the Prime `Theme` object, light. Pass it to `ThemeUtils.setGlobalDefaultTheme(...)` or to any component's `theme` prop. See the [`svelte-tweakpane-ui` themes docs](https://kitschpatrol.com/svelte-tweakpane-ui/docs/themes).
- `primeThemeDark` optional dark variant, same shape, values mirroring the dark tokens in `@viamrobotics/tailwind-config/dark`. Tweakpane themes are applied via JS, not CSS, so there is no automatic `prefers-color-scheme` or `.dark` activation. The consumer decides which theme to pass to `ThemeUtils.setGlobalDefaultTheme`, for example by watching a `matchMedia('(prefers-color-scheme: dark)')` listener.
- `Theme` re-exported from `svelte-tweakpane-ui` for convenience.

Peer dependencies: `svelte ^5`, `svelte-tweakpane-ui ^1.5.16`.

## Layout

- `src/lib/` published source. `src/lib/index.ts` re-exports the public API.
- `src/lib/theme.ts` the Prime theme object, plain hex and rgba values.
- `src/routes/` SvelteKit playground app. Built statically and embedded under [apps/docs](../../apps/docs/) at `/playground/tweakpane-config/`. Not published.
- `dist/` generated by `tsc -p tsconfig.build.json` during `pnpm build`. What npm sees via the `files` field.

## Conventions

- Theme hex values mirror tokens in [`@viamrobotics/tailwind-config`](../tailwind-config/CLAUDE.md). They are inlined rather than referenced through `var(--color-*)` because `svelte-tweakpane-ui` does not reliably resolve CSS var references inside theme values. Changing a token in `tailwind-config.css` means updating [src/lib/theme.ts](./src/lib/theme.ts) to match.
- Token values must match the Viam design system at https://design.viam.com/. Never invent values, copy them from the published guides.
- This package is data-only: a theme object and a type. Where and when to call `ThemeUtils.setGlobalDefaultTheme` is the consumer's decision, given SSR and lazy-initialization concerns. Do not add a helper that wraps it.
- The playground's `+layout.svelte` calls `ThemeUtils.setGlobalDefaultTheme` inside `$effect` so it only runs on the client, since tweakpane touches `window`.
- Fonts are not bundled. Consumers load them separately via `@viamrobotics/tailwind-config/fonts` or `@fontsource-variable/public-sans`.

## Commands

```bash
pnpm --filter @viamrobotics/tweakpane-config dev      # start playground dev server
pnpm --filter @viamrobotics/tweakpane-config build    # tsc library + vite build playground
pnpm --filter @viamrobotics/tweakpane-config check    # svelte-check
pnpm --filter @viamrobotics/tweakpane-config format   # prettier formatter
pnpm --filter @viamrobotics/tweakpane-config lint     # eslint
```
