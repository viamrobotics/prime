@viamrobotics/tweakpane-config

@viamrobotics/tweakpane-config exposes a Theme preset that matches Viam’s design system. Drop it into svelte-tweakpane-ui’s ThemeUtils.setGlobalDefaultTheme and every component on the page renders with Viam’s palette and typography.

Installation

Section titled “Installation”

  1. Install the package and its peer:

    • pnpm
    • npm
    • yarn

  2. Apply primeTheme as the global default near the top of your app. Refer to the svelte-tweakpane-ui themes documentation for the supported usage patterns (global default, per-component theme prop, partial overrides).

Dark mode

Section titled “Dark mode”

primeThemeDark is the dark variant of primeTheme, with the same shape and values mirroring the dark tokens in @viamrobotics/tailwind-config.

Caution

Tweakpane themes are applied via JS, not CSS, so there is no automatic prefers-color-scheme / .dark activation. The consumer decides which theme to pass to ThemeUtils.setGlobalDefaultTheme and when.

Wire it to the OS preference yourself. This is consumer-owned glue, not a package export:

  • TypeScript
  • Svelte

Fonts

Section titled “Fonts”

The theme references Public Sans Variable. Load it via @viamrobotics/tailwind-config or directly from @fontsource-variable/public-sans. If the font isn’t loaded, browsers fall back to the system sans-serif.

Section titled “Blades”
