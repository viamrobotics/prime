@viamrobotics/prime-ui

@viamrobotics/prime-ui is Viam’s Svelte 5 component library. Components are built on top of design tokens from @viamrobotics/tailwind-config and styled with Tailwind CSS v4.

Pre-1.0

The v2 of prime is under active development. The public API is unstable. Expect breaking changes until 1.0.

Installation

Section titled “Installation”

  1. Install the package, its svelte peer, and tailwindcss to compile the classes. @viamrobotics/tailwind-config comes with the package as a dependency, and installing it directly as well gives your own classes the same tokens:

    • pnpm
    • npm
    • yarn

  2. In your app’s main CSS, import Tailwind and the prime-ui stylesheet:

    Tailwind v4 skips node_modules when it detects which classes to generate, so the package ships a stylesheet that points Tailwind at its compiled components. It also imports the tokens from @viamrobotics/tailwind-config and declares the @source. Import it even if you also add your own @source: the tokens it imports carry the component classes (input, focus-ring) the controls wear, and an @source alone would leave every control without them.

Usage

Section titled “Usage”

Focus ring

Section titled “Focus ring”

Every prime control shows the same focus indicator: a 2px link blue outline, offset 2px, on :focus-visible. It is an outline rather than a ring box-shadow so it survives Windows forced-colors mode and never collides with a real shadow. The tokens package defines it as two component classes you can reuse on your own controls so they match:

ClassUse it on
focus-ringThe focusable element itself. Also sets outline: none so the browser’s default ring does not double.
focus-ring-withinA frame whose focus lives on a child, the way Input.Group wraps an Input.

Buttons show the ring for keyboard focus only. Text inputs match :focus-visible on any focus, so they ring on click too, as native inputs do.

Icons

Section titled “Icons”

Icon takes an SVG path string or a Svelte icon component. Install @mdi/js for the Material Design icons, and import the Viam glyphs from @viamrobotics/prime-ui/icons.
