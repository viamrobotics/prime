Textarea

A native multi-line text input with the Viam border and padding. Inside a Field it takes its id (the field’s controlId), disabled, required, state, and aria-describedby from there. It grows with its content where the browser supports field-sizing: content, and shows rows lines elsewhere.

<Textarea
  rows={3}
  placeholder="Describe the machine"
  disabled={false}
  readonly={false}
/>
  • A real <textarea>, so every native attribute and event handler passes straight through.
  • Grows with its content where the browser supports field-sizing: content, and shows rows lines elsewhere.
  • Three contextual states, info, warn, and error, styled like Input.
  • Reads controlId, disabled, required, state, and aria-describedby from an enclosing Field.

Styling

Section titled “Styling”

class lands on the <textarea>. It has no wrapper and no width, so set one yourself or let a flex or grid parent stretch it.

The border, padding, and state colors are the input component class from @viamrobotics/tailwind-config, the same one Input wears. Height comes from field-sizing: content, with rows as the fallback in browsers without it.

HookWhere
data-field-stateOn the textarea for info, warn, and error
aria-invalidOn the textarea in the error state
