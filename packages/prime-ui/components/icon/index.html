Icon

Renders an icon: an SVG path string (such as an @mdi/js export) drawn on a 24×24 viewBox, or any Svelte icon component rendered directly. Decorative by default. Pass aria-label or aria-labelledby to make it informative. It then gets role="img" instead of aria-hidden.

icon accepts an SVG path string or a Svelte component. A string is the d attribute of a path on a 24 by 24 viewBox, which is what every @mdi/js export is. A component renders as is, so any icon library that ships Svelte components works.

  • size takes one of eight tokens, xs through 4xl, from iconSizes in packages/prime-ui/src/lib/Icon/icon.ts. Color follows currentColor.
  • Decorative by default: aria-hidden and not focusable. Add an aria-label when it stands alone.
  • Icon bundles no paths of its own. Your bundler keeps only the icons you import.

An informative icon

Section titled “An informative icon”

An icon with no visible text next to it needs a name. Pass aria-label or aria-labelledby, and the icon gets role="img" and stops being hidden from assistive technology.

Why there is no icon set

Section titled “Why there is no icon set”

prime ships no general icon set. It ships only the Viam glyphs, under @viamrobotics/prime-ui/icons. For everything else, bring @mdi/js or another library and import only what you render.

Styling

Section titled “Styling”

class lands on the <svg>, next to the size class. Set color with a text-* token, since the paths fill with currentColor.

Migrating from the curated names

Section titled “Migrating from the curated names”

Before this release Icon took a curated kebab-case name such as icon="cog". Names are gone, so replace each with the import below.

The tables cover a name written in markup. An icon that arrives as data, such as name={option.icon} or a field typed IconName, needs a map on your side from your own keys to the imports you use, since Icon no longer carries one. Keep that map to the names your app renders.
