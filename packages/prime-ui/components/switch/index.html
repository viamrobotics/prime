Switch

An on/off switch. Inside a Field it takes its id (the field’s controlId), disabled, required, state, and aria-describedby from there. An error state sets aria-invalid. Always pair it with a Label. A switch-info, switch-success, switch-warning, or switch-danger class sets the track color while it is on.

Built on bits-ui Switch.

<Switch
  checked={false}
  disabled={false}
/>
  • Two states, on and off, driven by one bindable prop: checked.
  • Keyboard and screen reader behavior from the WAI-ARIA switch pattern, via bits-ui.
  • Submits with the form through a hidden <input> when given a name.
  • The label is static. It describes the setting and does not change when the switch flips.

Usage

Section titled “Usage”

Two-way binding

Section titled “Two-way binding”

bind:checked keeps your state and the switch in sync. State & binding covers both modes.

Fully controlled

Section titled “Fully controlled”

Give bind:checked a getter and a setter. Here the switch can be turned on but never off. State & binding has the rule.

In a field

Section titled “In a field”

Put the switch and a Label in a Field. The switch takes controlId, disabled, required, state, and aria-describedby from the field, and the label and hint wire themselves to it. name and value make it part of the enclosing form. A state of error sets aria-invalid="true" and turns the track red.

Revealing content

Section titled “Revealing content”

A switch can show more settings when it is on. Read checked and render the extra fields below the switch.

Styling

Section titled “Styling”

class lands on the root button, which is the track. The thumb is inside it and is not exposed. The tone classes switch-info, switch-success, switch-warning, and switch-danger set the track color while the switch is on, and an error state still paints over them. bits-ui sets these attributes on the track, so Tailwind variants like data-[state=checked]:bg-light work without a wrapper.

Attribute Value
data-state checked or unchecked
data-disabled present when disabled
aria-invalid true when state is error
