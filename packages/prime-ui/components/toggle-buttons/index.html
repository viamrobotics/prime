ToggleButtons

A row of mutually exclusive buttons, one of which is selected. Give it items, or compose options with ToggleButtons.Item. Inside a Field it takes its id (the field’s controlId), disabled, state, aria-labelledby, and aria-describedby from there.

Built on bits-ui ToggleGroup.
  • One value for the whole group, bindable. Options come from items, or from ToggleButtons.Item children.
  • One option is always selected: clicking the selected option does not clear it.
  • Takes state, disabled, and its labelling from an enclosing Field, or directly. error sets aria-invalid="true" on the group.
  • Arrow keys move focus between options without selecting. Enter or Space selects.
  • Each option is a role="radio" button inside a role="group", and the selected one carries data-state="on".

Anatomy

Section titled “Anatomy”

Pass items for the common case, or compose the options yourself with ToggleButtons.Item when they need more than text.

Usage

Two-way binding

Section titled “Two-way binding”

bind:value on the group. The items need no binding of their own.

Composed options

Section titled “Composed options”

ToggleButtons.Item children hold any content, such as an icon beside the text. Give an icon-only option an aria-label.

Fully controlled

Section titled “Fully controlled”

Pass bind:value a getter and a setter. The setter can decline a change. State & binding explains both modes.

In a field

Section titled “In a field”

Inside a Field, the group takes its id, disabled, state, and the aria-labelledby and aria-describedby from the Label and Hint.

Keyboard

Section titled “Keyboard”

Arrow keys move focus only. Selecting is a separate key press.

KeyAction
TabFocuses the selected option, or the first.
ArrowRight / ArrowDownMoves focus to the next option, wrapping around.
ArrowLeft / ArrowUpMoves focus to the previous option, wrapping.
Home / EndMoves focus to the first or last option.
Enter / SpaceSelects the focused option.

API

Section titled “API”
PropTypeDefaultDescription
bind:valuestringThe selected value. Two-way bindable.
itemsToggleButtonsOption[]Options rendered as items, in order. Omit to compose ToggleButtons.Item children.
disabledbooleanDisable every option. Defaults to the enclosing field's disabled.
stateFieldStateContextual state. Defaults to the enclosing field's state.

Plus everything in Omit<HTMLAttributes<HTMLDivElement>, 'onchange'>, spread onto the element.

ToggleButtons.Item
