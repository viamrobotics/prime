MultiSelect

A select that holds several values. Render MultiSelect.Trigger, MultiSelect.Portal, MultiSelect.Content, MultiSelect.Viewport, and MultiSelect.Items inside it, the same parts a Select takes. Picking an item toggles it and keeps the list open. The closed trigger shows the selected labels joined by commas, and a name submits one hidden input per value. Inside a Field it takes disabled and required from there.

Built on bits-ui Select with type="multiple".
  • The same parts as Select, under MultiSelect.*. The trigger, the panel, and each item are yours to arrange.
  • value is a string[], bindable, in the order the values were picked. Picking an item toggles it and the list stays open.
  • The closed trigger shows the selected labels joined by commas, and a name submits one hidden input per value.
  • items is the single source of truth for the options, as on Select. Typing while the list is closed toggles the matching entry.
  • Keyboard navigation, typeahead, and the WAI-ARIA listbox pattern, via bits-ui.

Anatomy

Section titled “Anatomy”

The parts are the Select parts, so the Select anatomy applies with MultiSelect in place of Select. Portal and Content are required for the panel to float, Viewport is the scrolling region, and Items renders every entry of items.

Usage

Section titled “Usage”

Two-way binding

Section titled “Two-way binding”

bind:value on the root holds an array. Pass the options as items and render them with <MultiSelect.Items />.

Fully controlled

Section titled “Fully controlled”

Pass bind:value a getter and a setter. The setter receives the whole next array, so it can cap how many values are held. State & binding explains both modes.

Styling

Section titled “Styling”

Everything on the Select styling section applies: class lands on each part’s element, MultiSelect.Trigger carries no width of its own, and bits-ui sets the same data attributes. MultiSelect.Item carries data-selected on every selected item at once.

Keyboard

Section titled “Keyboard”

The Select keyboard table applies, with two differences while the panel is open:

KeyAction
Enter / SpaceToggles the highlighted item. The panel stays open.
EscapeCloses the panel. The values picked so far are kept.

API

Section titled “API”
PropTypeDefaultDescription
itemsSelectOption[]The options, and the single source of truth for the select. [Select.Items](./SelectItems.svelte) renders one option per entry. The closed trigger shows the selected entries' labels. Typing while the list is closed toggles the matching entry without opening it.
bind:valuestring[]The selected values, in the order they were picked. Two-way bindable.
namestringName for form submission. Submits one input per selected value.
disabledbooleanDisable the select. Defaults to the enclosing field's disabled.
requiredbooleanRequire at least one selection. Defaults to the enclosing field's required.
childrenSnippetThe MultiSelect.* parts.

The parts are documented on Select.
