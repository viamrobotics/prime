Banner

A notification banner: an icon chip, content, and an optional dismiss button. The variant picks the chip color and glyph, and the live-region role: status for info, success, and pending, alert for warning and danger. pending wears a spinner in the chip for work still running. Without a Banner.Title it is a compact one-liner, with one it stacks. The banner owns no open state, so render it inside an {#if} to show and hide it.

Module deprecated

my-camera uses a module that is no longer maintained.
  • variant sets the chip color, the glyph, and the live-region role. info, success, and pending are status, warning and danger are alert. pending spins in the chip.
  • With no Banner.Title the banner is the compact one-liner. A title stacks it.
  • The parts give you the layout. Each lands in its own cell, so what goes inside is your markup.
  • It has no open state. Wrap it in {#if} to show and hide it.
  • placement="block" is the full-width strip for the top of a page.

Anatomy

Section titled “Anatomy”

Every part is a property on Banner. A banner renders a <div>.

Usage

Section titled “Usage”

Stacked

Section titled “Stacked”

A title, a description, and an actions row. Use the neutral button class for the emphasized action and text-sm font-medium text-link for a secondary one.

Compact

Section titled “Compact”

Leave the title out and the description sits on one line, with the actions inline beside it.

Dismissable

Section titled “Dismissable”

Banner.Close takes a native onclick. The banner holds no state, so the consumer owns {#if}.

Pending

Section titled “Pending”

variant="pending" shows a spinner in the chip for work still running. Banner.Progress pins a bar to the bottom edge, such as a countdown, and Banner.Icon replaces any variant’s glyph with your own.

With details

Section titled “With details”

Banner.Details is a disclosure under a divider. Its content is set in small monospace type.

Block

Section titled “Block”

placement="block" drops the side and top borders and spans the full width.

Styling

Section titled “Styling”

Every part takes class on its element. Each part wears a component class from Component classes, so the same look works without Svelte.

Part Component class
Banner banner, banner-<variant>, and banner-block for the block placement
Banner.Icon banner-chip
Banner.Title banner-title
Banner.Description banner-description
Banner.Actions banner-actions
Banner.Details banner-details
Banner.Close icon-button banner-close
Banner.Progress progress banner-progress

Banner.Details is built on Collapsible, so bits-ui sets its attributes.

Details data-state open or closed

API

Section titled “API”
PropTypeDefaultDescription
idstringElement id. null is not accepted.
variantBannerVariant'info'The tone: chip color, default glyph, and live-region role.
placement'inline' | 'block''inline'block spans the full width with only a bottom border.
roleHTMLAttributes<HTMLDivElement>['role']The live-region role. Defaults by variant: status for info, success, and pending, alert for warning and danger. Pass null for none, when an ancestor already announces.

Plus everything in HTMLAttributes<HTMLDivElement>, spread onto the element.

Banner.Actions

A row of actions in a Banner. It holds whatever the consumer puts in it, such as a button and a link. In the compact banner it sits inline on the right.

Takes extraClasses, children, ...restProps }: Props as its props.

Banner.Close

The dismiss button of a Banner, labelled Dismiss. It renders a close icon by default. Pass children to replace the icon, and aria-label to replace the label. The banner owns no open state, so handle onclick and remove the banner yourself.

PropTypeDefaultDescription
idstringElement id. null is not accepted.

Plus everything in HTMLButtonAttributes, spread onto the element.

Banner.Description

The body copy of a Banner.

Takes extraClasses, children, ...restProps }: Props as its props.

Banner.Details

A disclosure under a divider in a Banner. The summary is the trigger label, and the children are the content, set in small monospace type.

PropTypeDefaultDescription
idstringElement id. null is not accepted.
bind:openbooleanfalseWhether the content is shown. Two-way bindable.
summarystring'Details'The trigger label.

Plus everything in HTMLAttributes<HTMLDivElement>, spread onto the element.

Banner.Icon

The icon chip of a Banner. Its children replace the variant glyph, such as a spinner for a pending state or a custom icon.

Takes extraClasses, children, ...restProps }: Props as its props.

Banner.Progress

A Progress pinned to the bottom edge of a Banner, inside the border. It takes Progress’s props.

Takes extraClasses, ...restProps }: Props as its props.

Banner.Title

The heading line of a Banner. Its presence switches the banner from the compact one-liner to the stacked layout.

Takes extraClasses, children, ...restProps }: Props as its props.
