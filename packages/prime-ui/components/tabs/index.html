Tabs

A tab strip with one panel per tab. Compose it from Tabs.List holding one Tabs.Trigger per tab, and one Tabs.Content per tab. The first tab is selected until the user picks another, and a selection whose tab is gone falls back to the first.

Built on bits-ui Tabs.

Overview
Usage
API

Overview panel

Usage panel

API panel
  • Composed from parts, so the list, each tab, and each panel are yours to arrange.
  • The first tab is selected until the user picks another. A selection whose tab is removed falls back to the first remaining tab.
  • value on the root is bindable, two-way or as a getter and setter. State & binding explains both modes.
  • Activation is automatic: ArrowLeft, ArrowRight, Home, and End move focus and select.
  • Each Tabs.Trigger is a role="tab" element, not a <button>, so a control can sit inside it.
  • A strip with one tab is a bar with nothing to switch between. Wrap Tabs.List in {#if} when the count can drop to one.
  • Navigation tabs, links marked with aria-current, are styled anchors, not this component.

Anatomy

Section titled “Anatomy”

Every part is a property on Tabs. Pair each Tabs.Trigger with a Tabs.Content that has the same value. Name the strip with aria-label or aria-labelledby on Tabs.List.

Usage

Section titled “Usage”

Two-way binding

Section titled “Two-way binding”

bind:value on the root holds the value of the selected tab.

Fully controlled

Section titled “Fully controlled”

Pass bind:value a getter and a setter. The setter can decline a change.

Icons

Section titled “Icons”

A trigger’s children are its content, so an icon sits beside the label.

Controls inside a tab

Section titled “Controls inside a tab”

A control nested in a tab keeps its own key events, so Enter and Space reach it. Its click handler should call event.stopPropagation(), or the click also selects the tab. Closing the selected tab falls back to the first remaining tab, and the list hides at one tab.

Tabs.Content

The panel a Tabs strip shows while the tab with the same value is selected.

Takes extraClasses, children, ...restProps }: Props as its props.

Tabs.List

The strip that holds a Tabs root’s triggers. Give it an aria-label or aria-labelledby. A strip with one tab is a bar with nothing to switch between, so render it only when there are two or more.

Takes extraClasses, children, ...restProps }: Props as its props.

Tabs.Trigger

One tab of a Tabs strip. Its children are the tab’s content. It is a role="tab" element rather than a <button>, so a control such as a close icon-button can sit inside it; that control’s keys stay with it, and it stops click propagation so the click does not select the tab.

Takes extraClasses, children, ...restProps }: Props as its props.
