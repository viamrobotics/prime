# @viamrobotics/prime-charts

Svelte 5 charts built on LayerCake, themed with Viam's design tokens.

> [!NOTE]
> Under active development. The public API is unstable until 1.0.

## Installation

```sh
pnpm add @viamrobotics/prime-charts @viamrobotics/tailwind-config
```

Requires `svelte` `^5.40.0`. Import the stylesheet once, after Tailwind:

```css
@import 'tailwindcss';
@import '@viamrobotics/prime-charts/styles.css';
```
