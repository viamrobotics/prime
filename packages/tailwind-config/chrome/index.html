Chrome classes

The chrome classes are @utility classes shipped by @viamrobotics/tailwind-config. They style native elements, bits-ui triggers in prime-ui (<Dialog.Close class="icon-button">), and markup outside Svelte.

A bare class is the design-system default. A modifier beside it recolors, as in class="button button-primary". Utilities written after the class win, so class="button px-4" overrides the padding.

button

Section titled “button”

Modifiers: button-primary, button-ghost, button-danger, button-outline-danger, and button-success.

StateAttributeWhat changes
Disabled:disabled or [aria-disabled="true"]Disabled colors and a not-allowed cursor, with no hover.
Busy[aria-busy="true"]The cursor becomes progress.

A leading icon is an inline <svg> placed as the first child.

The busy button sets aria-busy="true" and puts a progress-dots span first.

icon-button

Section titled “icon-button”

Modifiers: icon-button-secondary and icon-button-danger.

StateAttributeWhat changes
Disabled:disabled or [aria-disabled="true"]Gray icon, not-allowed cursor, no hover.
Busy[aria-busy="true"]The cursor becomes progress.

Name the button

An icon-button has no visible text, so it must carry aria-label or aria-labelledby.

DisabledRead only

On a plain <span>, aria-disabled and aria-readonly are CSS hooks only. Assistive technology reads no state from them, so a removable pill signals its state through the remove button’s own disabled attribute.

StateAttributeWhat changes
Disabled[aria-disabled="true"]Disabled colors and a not-allowed cursor.
Read only[aria-readonly="true"]Disabled colors, with the default cursor.

avatar

Section titled “avatar”

Initials are the content. An <img> child fills the circle.

al

The avatar has no states.

Label the avatar

An avatar carries role="img" and aria-label, because initials alone do not name the person.

progress-dots

Section titled “progress-dots”

A braille spinner. It freezes on its first frame under prefers-reduced-motion: reduce.

Loading

progress-dots has no states.

Give it a label

progress-dots carries role="status" and a visually hidden label as a child. Inside a busy button, hide it with aria-hidden="true" and let aria-busy carry the meaning.

input

Section titled “input”

The frame for a text field. Put it on a native <input>, or on a wrapper around a bare <input> to build a group with a leading icon or trailing button.

Each state also applies when the attribute sits on a direct child <input> of the frame.

StateAttributeWhat changes
Hover:hoverA darker border.
Invalid[aria-invalid="true"]A danger border.
Warning[data-field-state="warn"]A warning border.
Read only[readonly]A transparent border and a gray background.
Disabled:disabled or [data-disabled]Disabled colors and a not-allowed cursor.

Later states win ties. Disabled and read only beat invalid and warning, and every state beats hover.

Warning state

input reads data-field-state="warn". prime-ui’s Field sets it, and plain markup can set it directly.

focus-ring and focus-ring-within

Section titled “focus-ring and focus-ring-within”

focus-ring draws a 2px outline offset by 2px on :focus-visible. button, icon-button, and input already include it. focus-ring-within draws the same ring on a frame whose focus lives on a child, and it silences the child’s own ring.

Focusable link
StateAttributeWhat changes
Keyboard focus:focus-visible (focus-ring)The outline appears.
Focus inside:has(:focus-visible) (focus-ring-within)The outline appears on the frame.

Not shipped

Section titled “Not shipped”

Variants of the @viamrobotics/prime-core components that are not on the design-system pages are not included: button ghost-outline, outline-success, pending, disabled-dark, width, height, and textSize. For icon-button, ghost, ghost-outline, danger-filled, dark, and size="large". For badge, pending and progress. For pill, dark, info, and warning. For kbd, dark.

See every class live on the playground. The package overview is at tailwind-config.
