Viam Prime

Component libraries and design system documentation for Viam apps.
Explore prime-uiBrowse the components

Prime is Viam’s design-system implementation: a set of npm packages that share design tokens (@viamrobotics/tailwind-config) and ship Svelte 5 components on top of them (@viamrobotics/prime-ui). This site documents what’s available, with live demos and usage recipes for each package.

Packages

Section titled “Packages”

@viamrobotics/prime-ui

Viam’s Svelte 5 component library. See the package docs for installation, or the component pages for live demos and usage.

@viamrobotics/tailwind-config

Shared Tailwind CSS v4 design tokens and fonts. See the package docs for usage and token references.

@viamrobotics/tweakpane-config

Viam-themed preset for svelte-tweakpane-ui. See the package docs for usage.

@viamrobotics/prime-panes

Resizable, rearrangeable split-pane layouts for Svelte 5. See the package docs for usage and a migration guide.

@viamrobotics/prime-tree

Headless tree view for Svelte 5. The package owns behavior and accessibility, and you own every row. See the package docs for usage and the snippet contract.
