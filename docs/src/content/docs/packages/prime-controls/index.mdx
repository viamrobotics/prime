`@viamrobotics/prime-controls` is a set of compact realtime controls for tool panels. Each number control steps by keyboard and scrubs by dragging its label sideways, so a value can be tuned live without typing. Containers group the controls into panels, folders, and tabs.

<Aside type="caution">
  The public API is unstable until 1.0. Expect breaking changes in minor
  releases.
</Aside>

- `NumberField`, one number with a label that doubles as the scrub handle.
- `Point`, a 2D, 3D, or 4D vector as one `NumberField` per axis.
- `Slider`, a range input with a `NumberField` readout beside it.
- `Panel`, `Folder`, and `Tabs`, the containers that group controls at tool panel scale.
- A scrub or a drag writes the bound value on every pointer move, so a function binding sees each intermediate value.

## NumberField

`NumberField` wraps a native `<input type="number">` with an optional visible `label`. Without a `label`, pass `aria-label`, and the field does not scrub.

### Two-way binding

`bind:value` holds the number, or `undefined` while the field is empty. Drag the label sideways to scrub, or focus the input and press the arrow keys.

<Example code={twoWaySource} title="TwoWay.svelte">
  <TwoWay client:visible />
</Example>

### Function binding

A scrub writes on every pointer move, so a function binding receives each intermediate value. Use one to throttle, to veto by not assigning, or to count writes as this recipe does.

<Example code={controlledSource} title="Controlled.svelte">
  <Controlled client:visible />
</Example>

### Range and step

`min` and `max` clamp scrubs and key presses, while typing stays unclamped. `step` is the amount one key press or one pixel of scrub moves the value, and a fractional step keeps its decimal places, so 0.05 steps never show float residue.

<Example code={boundsSource} title="Bounds.svelte">
  <Bounds client:visible />
</Example>

### Keyboard and pointer

| Input                          | Action                                                   |
| ------------------------------ | -------------------------------------------------------- |
| Arrow Up / Arrow Down          | Raise or lower the value by `step`                       |
| Shift + Arrow Up / Arrow Down  | Step by 10 times `step`                                  |
| Alt + Arrow Up / Arrow Down    | Step by a tenth of `step`                                |
| Drag the label sideways        | Scrub, moving the value by `step` for each pixel         |
| Shift or Alt while scrubbing   | Scale each pixel by 10 or by a tenth                     |
| Click the label                | Focus the input                                          |
| Slider: Arrow Left / Right / Up / Down | The range moves by `step`, natively              |
| Slider: Home / End             | The range jumps to `min` or `max`, natively              |
| Slider: readout                | Steps like a `NumberField`, without scrubbing            |

A drag begins once the pointer moves 4 pixels from where it was pressed, and only the primary button scrubs. A `disabled` or `readonly` field neither steps nor scrubs. An empty field starts from `min`, or 0 without one.

## Point

`Point` binds a `PointValue`, an object with `x` and `y` and optionally `z` and `w`. The defined axes decide how many fields render. Editing one axis writes a new object with that axis changed and the others as they were. `min`, `max`, `step`, and `disabled` apply to every axis.

## Panel

`Panel` is the dense container for a tool panel's controls, a `role="group"` with a border and tight spacing. A visible `title` names the group. Without one, pass `aria-label`.

<Example code={panelTitleSource} title="PanelTitle.svelte">
  <PanelTitle client:visible />
</Example>

## Folder

`Folder` is a collapsible group inside a panel. Its `title` is the text of the button that opens and closes it. It is open by default, and `bind:open` reads and sets the state.

<Example code={folderOpenSource} title="FolderOpen.svelte">
  <FolderOpen client:visible />
</Example>

## Tabs

`Tabs` is a compound of `Tabs.List`, `Tabs.Trigger`, and `Tabs.Content`. It wraps the prime-ui parts at panel scale, so the props and the keyboard behavior are prime-ui's. `bind:value` holds the selected tab, and each `Tabs.Content` shows while its `value` is selected. Give `Tabs.List` an `aria-label`.

<Example code={tabsModesSource} title="TabsModes.svelte">
  <TabsModes client:visible />
</Example>

## Slider

`Slider` pairs a native `<input type="range">` with a `NumberField` readout. The visible `label` names both. Without it, pass `aria-label`. `min`, `max`, and `step` apply to both, and the readout steps like a `NumberField` without scrubbing.

<Example code={sliderBoundsSource} title="SliderBounds.svelte">
  <SliderBounds client:visible />
</Example>

### Function binding

A drag writes on every pointer move, so a function binding receives each intermediate value, as it does for `NumberField`. This one counts the writes.
