`@viamrobotics/prime-map` is a set of MapLibre maps for Svelte 5. A `MapLibre` fills its parent and hands the map to the markers, controls, and layers inside it.

<Aside type="caution">
  The public API is unstable until 1.0. Expect breaking changes in minor
  releases.
</Aside>

<Demo client:only="svelte" />

- `MapLibre`, a map on OpenStreetMap or Google Maps tiles, with a reactive context for its children.
- `MapLibreMarker` and `DirectionalMarker`, a pin and a heading arrow.
- `CenterControls`, `FollowControls`, `NavigationControls`, and `SatelliteControls`.
- `LngLatInput`, a latitude and longitude pair of fields.
- Mercator and Cartesian conversions between longitude and latitude and meters.
- A Three.js bridge on `@viamrobotics/prime-map/three` that renders a scene on the map.

## Usage

`MapLibre` fills its parent, so give the parent a size. `bind:center` and `bind:zoom` follow the camera, `bind:satellite` follows the satellite view, and `bind:map` gives the maplibre-gl `Map`. Its children mount once the map loads its first style. A child reads the map through `useMapLibre()`, whose `map`, `center`, `zoom`, `maxZoom`, `size`, `mapProvider`, `apiKey`, and `satellite` are reactive, and listens to a map event with `useMapLibreEvent(event, listener)`. Both throw outside a `MapLibre`.

### Markers

`MapLibreMarker` draws maplibre-gl's pin, or an `element` you pass. `DirectionalMarker` draws an arrow that points along `rotation`, clockwise in degrees.

<Example code={markersSource} title="Markers.svelte" height="20rem">
  <Markers client:only="svelte" />
</Example>

### Coordinates

`LngLatInput` needs no map. It calls `oninput` with a new `LngLat` when either field takes a number, and never for an empty field.

<Example code={coordinatesSource} title="Coordinates.svelte">
  <Coordinates client:visible />
</Example>

### Three.js

`useMapLibreThreeRenderer(scene, camera, render)` adds a custom layer that copies the map's projection onto `camera.current` and places every object whose `userData.lngLat` holds a `{ lng, lat }`. A `THREE.Line` takes a list of points. `useMapLibreThreeRaycast(camera)` returns a `pointer` and a `compute(raycaster)` for picking those objects. Import both from `@viamrobotics/prime-map/three`, and call them in a component inside a `MapLibre`.
