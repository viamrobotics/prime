- Determinate with `value` and `max`. `value` is clamped between 0 and `max`.
- Indeterminate without `value`, and `aria-valuenow` is left off.
- `label` is the accessible name, so always give one.
- The indeterminate slide stops under `prefers-reduced-motion: reduce`.

## Usage

### Determinate

Pass `value`, and `max` when the range is not 0 to 100.

<Example code={determinateSource} title="Determinate.svelte">
  <Determinate client:visible />
</Example>

### Indeterminate

Leave `value` out when the length of the task is unknown.

## Styling

`class` lands on the track, which wears the `progress` component class. The fill is the `.progress-fill` child. See [Component classes](../../tailwind-config/component-classes/) for the plain HTML form.

## Keyboard

The bar is not interactive, so it takes no keys.
