- A real `<textarea>`, so every native attribute and event handler passes straight through.
- Grows with its content where the browser supports `field-sizing: content`, and shows `rows` lines elsewhere.
- Three contextual states, `info`, `warn`, and `error`, styled like [`Input`](../input/).
- Reads `controlId`, `disabled`, `required`, `state`, and `aria-describedby` from an enclosing [`Field`](../field/).

## Styling

`class` lands on the `<textarea>`. It has no wrapper and no width, so set one yourself or let a flex or grid parent stretch it.

The border, padding, and state colors are the `input` [component class](../../tailwind-config/component-classes/) from `@viamrobotics/tailwind-config`, the same one `Input` wears. Height comes from `field-sizing: content`, with `rows` as the fallback in browsers without it.

| Hook               | Where                                            |
| ------------------ | ------------------------------------------------ |
| `data-field-state` | On the textarea for `info`, `warn`, and `error`  |
| `aria-invalid`     | On the textarea in the `error` state             |

## Keyboard
