- Composed from parts, so the trigger, the header, and the body are yours to arrange.
- One `open`, bindable. Closing returns focus to the trigger.
- Focus is trapped inside while open, Escape closes, and the page behind does not scroll, via bits-ui.
- The sheet fills the viewport in a portal. It has no overlay, border radius, or shadow, and it is labeled by `Takeover.Title`.

For a floating panel over a dimmed page, use [`Dialog`](../dialog/).

## Anatomy

Every part is a property on `Takeover`. `Takeover` renders no element. The body is your own markup inside `Takeover.Content`.

```svelte
<Takeover>
  <Takeover.Trigger />
  <Takeover.Content>
    <Takeover.Header>
      <Takeover.Title />
      <Takeover.Close />
    </Takeover.Header>
    <!-- body -->
  </Takeover.Content>
</Takeover>
```

## Migrating from prime-core

A prime-core `Takeover` was a single component driven by `isOpen` and `onClose`. Here it is a set of parts with a bindable `open`, and the trigger is a part.

| prime-core                  | Now                                                                  |
| --------------------------- | -------------------------------------------------------------------- |
| `Takeover`                  | `Takeover` with `Takeover.Trigger` and `Takeover.Content`.           |
| `isOpen`                    | `bind:open` on `Takeover`.                                           |
| `onClose`                   | Watch `open`, or pass a getter and setter. See [State & binding](../state/). |
| `cx` on `Takeover`          | `class` on `Takeover.Content`.                                       |
| `TakeoverHeader`            | `Takeover.Header`                                                    |
| `TakeoverTitle`             | `Takeover.Title`                                                     |
| `TakeoverClose`             | `Takeover.Close`                                                     |

## Styling

Every part that renders an element takes `class` on that element. `Takeover` renders no element, so it takes no `class`. `Takeover.Trigger` is a real `<button>` with no style of its own, so add `button` or your own classes. `Takeover.Close` wears `icon-button` and shows a close icon labeled `Close`. Pass children to replace the icon and `aria-label` to replace the label. With children it wears no class of its own, so `class="button"` gives a text close the `button` class alone. `Takeover.Content` wears `z-dialog`, so it sits on the same layer as [`Dialog`](../dialog/). See [z layers](../../tailwind-config/component-classes/#z-layers). bits-ui sets the data attributes in the table below.

| Part      | Attribute          | Value                                  |
| --------- | ------------------ | -------------------------------------- |
| `Trigger` | `data-state`       | `open` or `closed`                     |
| `Content` | `data-state`       | `open` or `closed`                     |
| `Content` | `data-nested`      | Present when inside another dialog     |
| `Content` | `data-nested-open` | Present while a nested dialog is open  |

## Keyboard

| Key                                                | Action                                                      |
| -------------------------------------------------- | ----------------------------------------------------------- |
| <kbd>Enter</kbd> / <kbd>Space</kbd>                | On the trigger, opens the takeover.                         |
| <kbd>Escape</kbd>                                  | Closes the takeover and returns focus to the trigger.       |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cycles focus inside the takeover, wrapping at either end.   |
