- Composed from parts, so the trigger, the panel, and the close button are yours to arrange.
- `open` is bindable, two-way or as a getter and setter. [State & binding](../state/) explains both modes.
- Non-modal: the page stays interactive while the panel is open.
- The panel floats in a portal, positioned to the trigger, and flips to the other side when there is no room.
- Closes on <kbd>Escape</kbd> and on a press outside, and returns focus to the trigger.

## Anatomy

Every part is a property on `Popover`. `Popover` renders no element. `Popover.Content` portals itself to the body. The panel is a dialog, so `Popover.Content` requires a name: an `aria-label`, an `aria-labelledby`, or a `label` it applies as its `aria-label`.

```svelte
<Popover>
  <Popover.Trigger />
  <Popover.Content aria-label="Details">
    ...
    <Popover.Close aria-label="Close" />
  </Popover.Content>
</Popover>
```

## Not modal

A popover does not lock page scroll, make the rest of the page inert, or trap focus, so the pointer and the keyboard still reach everything outside it. Focus moves into the panel when it opens. <kbd>Tab</kbd> from the panel's last control moves to the control after the trigger, and <kbd>Shift</kbd>+<kbd>Tab</kbd> from its first control moves back to the trigger. The panel stays open until <kbd>Escape</kbd> or a press outside closes it. Use a dialog when the user must answer before continuing.

## Styling

Every part that renders an element takes `class` on that element. `Popover.Trigger` is a real `<button>` with no look of its own beyond the focus ring, so add `button` or `icon-button`. `Popover.Close` wears `icon-button` while it shows its close icon. With children it wears no class of its own, so `class="button"` gives a text close the `button` class alone. `Popover` renders no element, so it takes no `class`. bits-ui sets the data attributes below. `Popover.Content` wears the `popover-panel` class, which carries the `shadow-popover` token, and the `z-popover` layer. See [z layers](../../tailwind-config/component-classes/#z-layers).

| Part      | Attribute    | Value                            |
| --------- | ------------ | -------------------------------- |
| `Trigger` | `data-state` | `open` or `closed`               |
| `Content` | `data-state` | `open` or `closed`               |
| `Content` | `data-side`  | the resolved side of the trigger |
| `Content` | `data-align` | the resolved alignment           |
