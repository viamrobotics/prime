- Composed from parts, so each link, the separators, and the current page are yours to arrange.
- A `nav` landmark wrapping an ordered list, so assistive technology announces it as a trail.
- `Breadcrumbs.Page` marks the current page with `aria-current="page"`, and it is text, not a link.
- `Breadcrumbs.Ellipsis` stands in for hidden crumbs, alone or inside a menu trigger.

## Anatomy

Every part is a property on `Breadcrumbs`. `Breadcrumbs` renders the `nav` and the `ol`, and each part renders a single element. `Breadcrumbs.Separator` is a direct child of the list.

```svelte
<Breadcrumbs>
  <Breadcrumbs.Item>
    <Breadcrumbs.Link />
  </Breadcrumbs.Item>
  <Breadcrumbs.Separator />
  <Breadcrumbs.Item>
    <Breadcrumbs.Ellipsis />
  </Breadcrumbs.Item>
  <Breadcrumbs.Separator />
  <Breadcrumbs.Item>
    <Breadcrumbs.Page />
  </Breadcrumbs.Item>
</Breadcrumbs>
```

## Migrating from prime-core

prime-core's `Breadcrumbs` took a `crumbs` array of strings and rendered the whole trail. Here you write the trail from parts, so each crumb can be a real link.

| prime-core                              | Now                                                                  |
| --------------------------------------- | -------------------------------------------------------------------- |
| `Breadcrumbs` with `crumbs`             | `Breadcrumbs` with one `Breadcrumbs.Item` per crumb.                 |
| `isDisabled`                            | Not carried over. Render a `Breadcrumbs.Page` instead of a link.     |
| `cx`                                    | `class`                                                              |
| `NavigationBreadcrumb`                  | `Breadcrumbs`                                                        |
| `NavigationBreadcrumbList`              | Folded into `Breadcrumbs`, which renders the list.                   |
| `NavigationBreadcrumbItem`              | `Breadcrumbs.Item`                                                   |
| `NavigationBreadcrumbLink`              | `Breadcrumbs.Link`                                                   |
| `NavigationBreadcrumbPage`              | `Breadcrumbs.Page`                                                   |
| `NavigationBreadcrumbSeparator`         | `Breadcrumbs.Separator`, placed between items and not inside one.    |
| `NavigationBreadcrumbEllipsis`          | `Breadcrumbs.Ellipsis`                                               |

## Styling

Every part takes `class` on the element it renders. `Breadcrumbs.Link` is muted and darkens on hover. `Breadcrumbs.Page` uses the default text color. `Breadcrumbs.Separator` is hidden from assistive technology, and `Breadcrumbs.Ellipsis` draws a horizontal dots icon labeled `More`. The list wraps onto a new line when the trail is wider than its container. Nothing here sets data attributes.

## Keyboard

Links are native, so <kbd>Tab</kbd> moves between them and <kbd>Enter</kbd> follows one.
