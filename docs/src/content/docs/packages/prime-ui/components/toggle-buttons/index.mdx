<ToggleButtonsDemo client:visible />

- One `value` for the whole group, bindable. Options come from `items`, or from `ToggleButtons.Item` children.
- One option is always selected: clicking the selected option does not clear it.
- Takes `state`, `disabled`, and its labelling from an enclosing [`Field`](../field/), or directly. `error` sets `aria-invalid="true"` on the group.
- Arrow keys move focus between options without selecting. <kbd>Enter</kbd> or <kbd>Space</kbd> selects.
- Each option is a `role="radio"` button inside a `role="group"`, and the selected one carries `data-state="on"`.

## Anatomy

Pass `items` for the common case, or compose the options yourself with `ToggleButtons.Item` when they need more than text.

```svelte
<ToggleButtons items={[{ value: "…", label: "…" }]} />

<ToggleButtons>
  <ToggleButtons.Item value="…">content</ToggleButtons.Item>
  <ToggleButtons.Item value="…">content</ToggleButtons.Item>
</ToggleButtons>
```

## Styling

`class` on `ToggleButtons` lands on the group `<div>`, which is `inline-flex`. `class` on `ToggleButtons.Item` lands on the item button, which wears `button`. bits-ui sets these data attributes for Tailwind variants.

| Element | Attribute       | Value                          |
| ------- | --------------- | ------------------------------ |
| group   | `aria-invalid`  | `true` when `state` is `error` |
| group   | `data-disabled` | present when disabled          |
| item    | `data-state`    | `on` or `off`                  |
| item    | `data-value`    | the item's `value`             |
| item    | `data-disabled` | present when disabled          |

## Keyboard
