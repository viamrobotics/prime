- Highlighting is done by prism, synchronously, so the colored code is in the first render. Eight grammars are bundled: bash, dart, go, javascript, json, python, rust, and typescript.
- The copy button writes `code` to the clipboard and reads `Copied` for two seconds, or `Copy failed` when the browser refuses the write.
- Token colors come from the code color tokens, which change in dark mode, so dark mode needs nothing extra.
- Long lines scroll sideways by default. Set `wrapLines` to wrap them instead.

## Styling

`class` and any other attributes land on the `<figure>` root. The `<pre>` wears `text-code` and `bg-light`. Every standard prism token class maps to one code token, grouped as below, so a grammar added later is colored with no new rules. Operators, punctuation, variables, and parameters inherit the text color.

| Prism classes | Color token |
| --- | --- |
| `comment`, `prolog`, `doctype`, `cdata`, `shebang`, `hashbang` | `--color-code-comment` |
| `keyword`, `atrule`, `important` | `--color-code-keyword` |
| `builtin`, `class-name`, `type-definition`, `generic`, `namespace`, `lifetime-annotation` | `--color-code-type` |
| `function`, `function-name`, `function-definition`, `macro`, `decorator`, `annotation` | `--color-code-function` |
| `string`, `char`, `template-string`, `triple-quoted-string`, `string-literal`, `attr-value`, `regex`, `url` | `--color-code-string` |
| `number`, `constant`, `symbol` | `--color-code-number` |
| `boolean` | `--color-code-boolean` |
| `null` | `--color-code-null` |
| `property`, `attr-name`, `tag`, `selector` | `--color-code-property-keys` |

`CodeSnippet` is native, so it sets no data attributes.

## Keyboard

The copy button is a native button, so <kbd>Tab</kbd> reaches it and <kbd>Enter</kbd> or <kbd>Space</kbd> copies.
