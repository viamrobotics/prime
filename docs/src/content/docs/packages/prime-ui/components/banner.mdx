- `variant` sets the chip color, the glyph, and the live-region role. `info` and `success` are `status`, `warning` and `danger` are `alert`.
- With no `Banner.Title` the banner is the compact one-liner. A title stacks it.
- The parts give you the layout. Each lands in its own cell, so what goes inside is your markup.
- It has no open state. Wrap it in `{#if}` to show and hide it.
- `placement="site"` is the full-width strip for the top of a page.

## Anatomy

Every part is a property on `Banner`. A banner renders a `<div>`.

```svelte
<Banner variant="warning">
  <Banner.Icon>...</Banner.Icon>
  <Banner.Title>title</Banner.Title>
  <Banner.Description>description</Banner.Description>
  <Banner.Actions>...</Banner.Actions>
  <Banner.Details summary="Details">...</Banner.Details>
  <Banner.Close onclick={dismiss} />
  <Banner.Progress value={elapsed} label="Time until dismissed" />
</Banner>
```

A title, a description, and an actions row. Use the neutral `button` class for the emphasized action and `text-sm font-medium text-link` for a secondary one.

## Styling

Every part takes `class` on its element. Each part wears a component class from [Component classes](../../tailwind-config/component-classes/), so the same look works without Svelte.

| Part                 | Component class                                                      |
| -------------------- | -------------------------------------------------------------------- |
| `Banner`             | `banner`, `banner-<variant>`, and `banner-site` for the site placement |
| `Banner.Icon`        | `banner-chip`                                                        |
| `Banner.Title`       | `banner-title`                                                       |
| `Banner.Description` | `banner-description`                                                 |
| `Banner.Actions`     | `banner-actions`                                                     |
| `Banner.Details`     | `banner-details`                                                     |
| `Banner.Close`       | `icon-button banner-close`                                           |
| `Banner.Progress`    | `progress banner-progress`                                           |

`Banner.Details` is built on `Collapsible`, so bits-ui sets its attributes.

| Part      | Attribute       | Value                 |
| --------- | --------------- | --------------------- |
| `Details` | `data-state`    | `open` or `closed`    |
| `Details` | `data-disabled` | present when disabled |

## Keyboard

| Key                                 | Action                                              |
| ----------------------------------- | --------------------------------------------------- |
| <kbd>Tab</kbd>                      | Focuses each action, the close button, and the details trigger. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On the details trigger, opens or closes the content. |
