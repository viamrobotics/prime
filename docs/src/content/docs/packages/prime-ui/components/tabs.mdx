<TabsDemo client:visible />

- Composed from parts, so the list, each tab, and each panel are yours to arrange.
- The first tab is selected until the user picks another. A selection whose tab is removed falls back to the first remaining tab.
- `value` on the root is bindable, two-way or as a getter and setter. [State & binding](../state/) explains both modes.
- Activation is automatic: <kbd>ArrowLeft</kbd>, <kbd>ArrowRight</kbd>, <kbd>Home</kbd>, and <kbd>End</kbd> move focus and select.
- Each `Tabs.Trigger` is a `role="tab"` element, not a `<button>`, so a control can sit inside it.
- A strip with one tab is a bar with nothing to switch between. Wrap `Tabs.List` in `{#if}` when the count can drop to one.
- Navigation tabs, links marked with `aria-current`, are styled anchors, not this component.

## Anatomy

Every part is a property on `Tabs`. Pair each `Tabs.Trigger` with a `Tabs.Content` that has the same `value`. Name the strip with `aria-label` or `aria-labelledby` on `Tabs.List`.

```svelte
<Tabs>
  <Tabs.List aria-label="Details">
    <Tabs.Trigger value="overview">Overview</Tabs.Trigger>
    <Tabs.Trigger value="usage">Usage</Tabs.Trigger>
  </Tabs.List>
  <Tabs.Content value="overview">...</Tabs.Content>
  <Tabs.Content value="usage">...</Tabs.Content>
</Tabs>
```

### Icons

A trigger's children are its content, so an icon sits beside the label.

<Example code={withIconsSource} title="WithIcons.svelte">

</Example>

### Controls inside a tab

A control nested in a tab keeps its own key events, so <kbd>Enter</kbd> and <kbd>Space</kbd> reach it. Its click handler should call `event.stopPropagation()`, or the click also selects the tab. Closing the selected tab falls back to the first remaining tab, and the list hides at one tab.

## Styling

The root and every part take `class` on their element.

| Part      | Attribute       | Value                  |
| --------- | --------------- | ---------------------- |
| `Trigger` | `data-state`    | `active` or `inactive` |
| `Trigger` | `data-disabled` | present when disabled  |
| `Content` | `data-state`    | `active` or `inactive` |

## Keyboard

| Key                                 | Action                                |
| ----------------------------------- | ------------------------------------- |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowRight</kbd> | Moves focus to the previous or next tab and selects it. |
| <kbd>Home</kbd> / <kbd>End</kbd>    | Moves focus to the first or last tab and selects it. |
| <kbd>Tab</kbd>                      | Moves focus into the selected panel.  |
