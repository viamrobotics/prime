- Each menu is a `Menubar.Menu` holding a `Menubar.Trigger` and a `Menubar.Content`.
- Shares every item part with [`Menu`](../menu/), so the item kinds, submenus, shortcuts, and selection are documented there.
- With one menu open, moving to a neighbouring trigger opens that menu, and the ends wrap around.
- Give the bar an `aria-label` so assistive technology can name it.

## Anatomy

Every part is a property on `Menubar`. `Menubar` renders the `role="menubar"` element, `Menubar.Menu` renders no element, and `Menubar.Content` portals itself to the body.

```svelte
<Menubar>
  <Menubar.Menu>
    <Menubar.Trigger />
    <Menubar.Content>
      <Menubar.Item />
      <Menubar.Separator />
    </Menubar.Content>
  </Menubar.Menu>
</Menubar>
```

## Styling

Every part that renders an element takes `class` on that element. `Menubar` lays its triggers out in a row, and `Menubar.Trigger` is a text button that highlights on hover, on focus, and while its menu is open. `Menubar.Content` wears `z-menu`; see [z layers](../../tailwind-config/component-classes/#z-layers). The data attributes on the item parts are the same as on [`Menu`](../menu/#styling).

## Keyboard

| Key                                          | Action                                                                  |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | On a trigger, moves focus to the next or previous trigger, wrapping.    |
| <kbd>ArrowDown</kbd> / <kbd>Enter</kbd> / <kbd>Space</kbd> | On a trigger, opens its menu and focuses the first item.  |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | In an open menu, opens the next or previous menu, or opens and closes a submenu. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd>    | Moves focus to the next or previous item.                               |
| <kbd>Home</kbd> / <kbd>End</kbd>             | Moves focus to the first or last item.                                  |
| Typed characters                             | Focuses the next item whose text starts with them.                      |
| <kbd>Enter</kbd> / <kbd>Space</kbd>          | On an item, activates it and closes the menu.                           |
| <kbd>Escape</kbd>                            | Closes the menu and returns focus to its trigger.                       |
